# ADR 0049, Release 1.5.3

- Status: aceito
- Data: 2026-11-06

## Decisão

Publicar a tag v1.5.3 com calibração das barrinhas, exclusão de abastecimentos, identificação da origem do consumo, aviso de atualização Android e preservação da referência após remover medições, conforme ADRs 0043 a 0048.

O pubspec usa 1.5.3+13. Na publicação, o nome vem da tag e o número do build vem de GITHUB_RUN_NUMBER. Os jobs de APK e web dependem da aprovação dos testes de API e app. O CI assina o APK e o anexa à Release com o nome permanente life-and-roads-beta-aberto.apk; a web usa o domínio app.raulnikroyce.dev.

A conferência anterior passou em 359 testes do app, análise Dart e compilação web. A main também passou nos jobs de API, app e preparo Android do GitHub. O wrapper Gradle é gerado com configuração Android antes do aquecimento do cache, sem compilar APK nessa etapa.

Sem alteração do banco da API ou migração de tabela local. As referências opcionais acompanham o JSON existente; históricos anteriores sem referência preservada mantêm a limitação descrita na ADR 0048.
