# ADR 0026, Release 1.2.1

- Status: aceito
- Data: 2026-09-18

## Contexto

O APK 1.2.0+5 dos pilotos ficou com o mapa marcado "API KEY REQUIRED" (CARTO passou a exigir chave) e sem as correções e o desenho novo feitos entre 17 e 18/09.

## Decisão

`pubspec` para `1.2.1+6`; tag `v1.2.1` gera o APK assinado no CI com `API_BASE` e `APP_VERSION`. Entram nesta release: refresh concorrente sem derrubar a sessão (ADR 0017), carimbo do servidor no sync (0018), aparelho primeiro (0019), backup enviável (0020), sync visível e crash com contexto (0021), mapa com alcance, links e tiles do OpenStreetMap (0022), UI viva (0023), logo vetorial (0024), Fase 22 de desenho (0025).

## Consequências

- Upload para os pilotos continua manual (artifact `app-release` do run da tag).
- API já estava em produção com as mudanças correspondentes (migrations 002 e 003).
- Redesenho de Manutenção, Viagem e Mapa como painéis fica para uma fase futura, a pedido do piloto.
