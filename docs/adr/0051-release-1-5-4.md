# 0051. Release 1.5.4

Data: 06/11/2026. Estado: publicação autorizada pelo usuário.

## Decisão

Publicar as quatro correções da auditoria documentadas na ADR 0050. O pubspec passa a 1.5.4+14; o CI define o build distribuído pelo número da execução. A sequência é enviar a main, aguardar testes e implantação da API, conferir o contrato público e a prontidão, e somente então publicar a tag v1.5.4 para gerar APK assinado e app web.

As migrations 006 a 008 rodam no início da API. Foram verificadas em banco descartável com preservação de dados antigos. A conferência em produção será pelo contrato servido pela nova versão e pelas rotas health/ready, sem alterar cadernetas pessoais.

A tag não deve ser enviada antes de confirmar a API nova. Clientes anteriores continuam aceitos sem conferência de versão; a proteção completa exige o app atualizado. As verificações locais passaram em 369 testes Flutter e 100 testes API sem skips, TypeScript e análise Dart. O flutter analyze local falhou no protocolo do SDK; o job do GitHub deve concluir a análise antes dos builds de distribuição.
