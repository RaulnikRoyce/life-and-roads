# Termos de uso, life.and.roads

Última atualização, 2026-08-26.

O **life.and.roads** é uma caderneta digital para **uma motocicleta**. O piloto registra ficha, manutenção, custo de viagem e o último ponto no mapa.

## O que o aplicativo faz

- Funciona neste aparelho, sem conta.
- A conta é opcional e replica só ficha, datas de manutenção e o último ponto, para troca de celular.
- Caderneta pessoal. Oficina, tabela FIPE, navegação passo a passo e rede social ficam de fora.

## O que você aceita

- Os números (média, litros, reais, autonomia) são estimativas. Confira no painel e na bomba.
- O mapa usa OpenStreetMap e o GPS do celular. Pode falhar em túnel, chuva ou sem sinal.
- Você é responsável pelos dados que grava. Placa, chassi e RENAVAM ficam de fora. O contrato da API recusa esses campos.

## Conta e exclusão

Cadastrar implica e-mail e senha (mínimo 8 caracteres). Você pode sair a qualquer momento e **excluir a conta no aplicativo** (Ficha, Conta, Excluir conta no servidor). Isso apaga os dados remotos. A caderneta local só some se você apagar o app ou restaurar um backup vazio.

## Limitação

O software é oferecido como está, para uso pessoal. A API pode ficar indisponível. Em dúvida, fique só no aparelho.
